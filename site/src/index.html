manyface

several AIs, one problem, one survivor

Ask one AI to solve a problem and you get a confident answer — but you cannot tell if it is actually right. Manyface runs several AIs side by side, each trying a different approach, then puts every answer through the same tough tests. A critic AI actively tries to break each answer. The one that survives wins. You see why the polished-but-wrong answers lost.

run a tournament

Launches 4 different sorting attempts against 3 critics. Every answer goes through the same deterministic tests.

how it works

problem
  ├─ Attempt A  (isolated cell) ──> answer + self-tests
  ├─ Attempt B  (isolated cell) ──> answer + self-tests
  ├─ Attempt C  (isolated cell) ──> answer + self-tests
  └─ Critic 1/2/3 ──> counterexamples

        deterministic tests
         pass / fail on every pair
             |
       winner (with proof bundle)
       losers (kept with counterexamples)

what powers it

  • Workflow — durable tournament lifecycle
  • Queues — fan-out for candidates and adversaries
  • Durable Object + SQLite — event-sourced tournament state
  • AI Gateway — model routing and per-role policy
  • Containers / Sandbox — isolated candidate execution cells
  • R2 — immutable artifacts, counterexamples, and receipts
