manyface

adversarial parallel synthesis

Race incompatible builders and hostile reviewers in isolation. The first artifact to survive the shared proof graph wins. Losers keep their failure receipts so nothing useful is thrown away.

run a tournament

Launches 4 sorting candidates against 3 adversarial reviewers. The gate scores every artifact deterministically.

how it works

claim
 ├─ Candidate A  (isolated cell) ──> artifact + self-tests
 ├─ Candidate B  (isolated cell) ──> artifact + self-tests
 ├─ Candidate C  (isolated cell) ──> artifact + self-tests
 └─ Adversary 1/2/3 ──> counterexamples

        deterministic gate
         pass / fail on every pair
            |
      winner (proof bundle)
      losers (retained with counterexamples)

load-bearing primitives

  • Workflow — durable tournament lifecycle
  • Queues — fan-out for candidates and adversaries
  • Durable Object + SQLite — event-sourced tournament state
  • AI Gateway — model routing and per-role policy
  • Containers / Sandbox — isolated candidate execution cells
  • R2 — immutable artifacts, counterexamples, and receipts
